CUMPLEAÑOS HOY — MAQUETA INSTALABLE

Archivos: subí TODOS los archivos de esta carpeta a un alojamiento web HTTPS. La página principal es index.html.

Instalación: en Android, abrí el enlace en Chrome y usá Instalar aplicación o Agregar a pantalla principal. En iPhone, abrí el enlace en Safari, tocá Compartir y luego Agregar a pantalla de inicio.

Notificaciones: el botón solicita permiso y permite mostrar una notificación de prueba en este dispositivo. IMPORTANTE: esta maqueta todavía NO tiene servidor de notificaciones push ni base de datos compartida. Por eso aún no puede enviar automáticamente invitaciones grupales a todos los integrantes con la aplicación cerrada. Para eso hace falta implementar y configurar un servicio push/backend, además de probarlo en Android y iPhone.

La maqueta no envía mensajes de WhatsApp sin confirmación del usuario.


ACTUALIZACIÓN DE ESTA ENTREGA

CONFIGURAR INVITACIONES GRUPALES CON FIREBASE
1. En Firebase Console > Authentication > Método de acceso, habilitar Anónimo.
2. En Cloud Firestore > Reglas, reemplazar el contenido por el archivo firestore.rules y pulsar Publicar.
3. Subir TODOS los archivos de este ZIP al repositorio de GitHub, reemplazando los archivos antiguos.
4. Abrir la aplicación desde el sitio HTTPS publicado. Al crear una partida, la aplicación guarda el juego en Firestore y comparte un enlace con ?partida=CODIGO.
5. El organizador debe conservar abierta la partida en la aplicación para ver las respuestas en vivo. Los invitados abren el enlace, escriben su nombre y eligen una respuesta.

IMPORTANTE:
- Las reglas permiten leer una partida solo por su código y a usuarios con sesión anónima; no permiten listar todas las partidas.
- El acceso anónimo no verifica la identidad real de una persona; los nombres son los que cada invitado escribe.
- Esto registra respuestas en la base de datos, pero NO envía notificaciones push cuando la app está cerrada. Para eso hace falta configurar Firebase Cloud Messaging y un backend confiable.
- No publiques claves privadas de servidor. La configuración web de Firebase incluida en index.html está destinada a la aplicación cliente.
